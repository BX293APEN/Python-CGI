# Python-CGI

## インストール方法
```bash  
pip install libcgipy
```

## 使い方

- 旧モジュール  
```python
import cgi
```

- 新モジュール  
```python
import pycgi
```

- 旧モジュール

import cgitb

```python
import pycgitb
```
